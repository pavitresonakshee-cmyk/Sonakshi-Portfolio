## 🚀 Overview

A professional, modern, attractive, unique, and fully responsive multi-page portfolio website designed for a Computer Engineering student specializing in Data Science. Built with a dark glassmorphic design system, purple & cyan glowing accents, interactive project detail modals, verified certificate viewers, and client-side form validation.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup, accessible page layouts, and optimized meta descriptions.
- **CSS3**: Modern CSS Variables, Flexbox, CSS Grid, Glassmorphism backdrop filters, custom keyframe animations, and responsive media queries (desktop down to 360px).
- **Vanilla JavaScript**: Pure JS without external framework dependencies for mobile drawer navigation, active link highlighting, project detail modals, Escape key listeners, scroll-reveal observers, and contact form validation.

---

## 📄 Website Pages

The portfolio is organized into separate HTML pages:

1. **`index.html`** — Home page featuring hero section, Quick CTAs, avatar frame with data node badges, and social links.
2. **`about.html`** — Background, education, career focus, and interactive interest cards.
3. **`skills.html`** — Categorized technical skills (Programming, Data Science, Databases, BI, Web, Tools) with proficiency indicators.
4. **`projects.html`** — Portfolio of database and software projects with interactive modal details.
5. **`experience.html`** — Factual timeline of Cisco Virtual Internship 2026.
6. **`certificates.html`** — Verified certificate gallery for Cisco Virtual Internship and JavaScript course with embedded PDF preview, view link, and download options.
7. **`resume.html`** — Resume profile summary and embedded PDF viewer with download interface.
8. **`contact.html`** — Direct contact details, clickable social cards, and a client-side validated contact form.

## 📦 How To Run Locally

1. Download or clone this repository folder to your local system.
2. Open the project folder in **Visual Studio Code** (or your preferred code editor).
3. Open `index.html` in your browser, or right-click `index.html` and select **Open with Live Server** if the Live Server extension is installed.
4. Navigate through all pages using the top navbar.
